BUI is a project that decouples Blender's battle-tested user interface and turns it into a standalone UI library with a small C core. Claude Code sends your email address to websites

⭐ 1222💬 387👤 motoroco

Users report that Claude Code silently sends the email address associated with their Anthropic account to external websites as part of API calls. The main trigger appears to be the SEC EDGAR API, whose documentation requires an email in the User-Agent header — so Claude dutifully fills it in without asking. The HN discussion treats this as a privacy and prompt-injection concern: an agent with network access will happily leak account details to whatever endpoint requests them, and approval-gating is the only realistic mitigation.

#7

sshole

⭐ 2749💬 665👤 josemrb

OpenSSH on musl-based Linux systems has a security flaw in which accounts configured to reject passwords can be logged into with any password longer than 256 characters. The issue stems from musl's crypt function returning an unmatchable asterisk on failure, which can coincidentally match the asterisk used to disable password authentication. As a result, root, key-only deploy, LDAP, and certain default cloud images may be exposed to unauthorized access.
