#9

Pi Durable

⭐ 394💬 50👤 paulsmith

Pi Durable is an experimental agentic framework shipped alongside Pi 1.0 by Earendil, built for long-running, durable agents that can run anywhere there is a JavaScript runtime. It shares Pi's minimalism and malleability principles, shipping with memory, SQLite, and JSONL storage backends plus a conformance suite for custom ones. The goal is a harness that survives failures, supports infinitely long conversations, and lets multiple humans steer the same agents.
