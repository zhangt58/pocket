PaperPilot – Zero-Cloud, Pure-Rust PDF Engine with WASM and MCP

⭐ 151💬 44👤 vardhan1237

PaperPilot is a PDF and document toolkit written in pure Rust that runs entirely locally — your files never leave your machine. A single engine powers an MCP server (letting Claude Desktop, Cursor, or any MCP client merge, split, OCR, and compress PDFs), a CLI, a browser-based WASM version, a Tauri desktop app, and a local REST API. Current features cover merging, splitting, rotating, compressing, pure-Rust OCR via PaddleOCR, watermarking, and PII scanning, with no Chromium or C++ runtime required.

#8

Show HN: A Truly Modular Keyboard

⭐ 173💬 57👤 NotARoomba

Keybytes is an open-source modular keyboard where every key is its own 1u PCB with a CH32V003 RISC-V microcontroller, connected via pogo pins on all four sides so keys can be freely rearranged into any layout. A stacked STM32WB55 main board provides Bluetooth, USB-C, 2MB QSPI flash for key firmware, battery charging, and an RGB status LED. The case holds modules together with magnets, and the full design is shared in KiCad and Onshape.

#9

Overgrown, when plants invade your abandoned tabs

⭐ 291💬 100👤 speckx

Overgrown is a Chrome extension that turns neglected browser tabs into overgrown digital jungles, with plants spreading from the edges as tabs sit unread. Once a tab is sufficiently covered, its content becomes inaccessible until the user drags a mouse to slash away the vines, using selectable tools like a machete, chainsaw, or flamethrower. The project is a playful creative experiment rather than a productivity tool, adding a fun obstacle to revisiting old tabs.
