Ruby2ßhell: Pre-authentication RCE on stock Rails

⭐ 178💬 68👤 jdns

Ruby2ßhell is a pre-authentication remote code execution vulnerability in Ruby that affects stock Rails and Sinatra applications by default. It is caused by a one-byte heap overflow when upcasing the ß character in certain single-byte encodings, allowing attackers to corrupt memory and potentially execute arbitrary code. The issue is fixed in Ruby 3.3.14, 3.4.13, and 4.0.10, and affected self-hosted products should be updated to vendor releases.
