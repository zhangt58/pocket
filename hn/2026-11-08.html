#8

Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files

⭐ 434💬 292👤 shmulc

Researchers found that Claude Code's "don't ask again" permission feature can store full shell commands, including passwords, API keys, and connection strings, in local settings files that developers sometimes commit to public GitHub repositories. The study identified 1,122 public copies of Claude Code settings files containing real secrets, with thousands of exposed credentials across nearly 2,000 repositories and 63 organizations. The issue arises because the saved permission rule includes the secret-bearing command, and the file is not reliably protected from being committed, so affected teams should search their repos and rotate any exposed credentials.
