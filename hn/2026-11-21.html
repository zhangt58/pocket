#4

RCE in Gnupg

⭐ 47💬 3👤 gdgghhhhh

GnuPG has released GPGME 2.3.1 to fix a critical double-free vulnerability in all earlier versions. The flaw can be triggered by an OpenPGP key with a crafted long user ID and may allow data exfiltration or, in some cases, remote code execution. Users should update GPGME and dependent applications such as Gpg4win, GnuPG Desktop, mail clients, and Samba.
